# ZHONNEX CORP — Enterprise Master Gateway Website

This repository dictates the public web storefront and the isolated executive workspace networks for **ZHONNEX CORP**. Hosted on **Vercel**, this layout integrates with our data schemas over secure environment hashes.

## 🗂️ Core Repository Directories
* `src/config/design-tokens.ts`: Encapsulates visual brand coloring matrix parameters.
* `src/components/HamburgerMenu.tsx`: The single isolated retractable hamburger side-menu tracking workspace links.
* `src/pages/index.tsx`: The deep-scroll customer landing page holding the cybernetic vector mesh layout.
* `src/pages/portal/terminal-access.tsx`: The private, un-indexed gate used to access internal employee tracks.
